# 央视频全频道直播 (YSP Live) · Docker 镜像

> 🌐 **对外展示文档**（Docker Hub Repository overview）。内部完整管理与命名规范见同目录 `使用说明书.html` 与 `NAMING.md`。

基于 [Gary's Club](https://t.me/garysclub) 发布的「央视频全频道直播」项目打包的**开箱即用 Docker 镜像**。  
一条命令部署后，通过标准 IPTV 订阅地址（`.m3u` + EPG）即可把全部央视频道接入任意主流播放器。

> ⚠️ 本项目为第三方直播源代理工具，**仅供个人学习研究使用**。  
> 首发地址：社区 [Gary's Club](https://t.me/garysclub) · 频道 [Gary's Club Channel](https://t.me/garysclubchannel)。其他任何分发渠道均非作者本人！

---

## ✨ 核心亮点

- **真 4K 超高清**，内置全部 **64 路**独立频道（央视 30 + 卫视 34）
- **原生 7 天时移回看**，完美适配 TiviMate / APTV / PotPlayer / VLC 等主流播放器
- **双引擎四层全自动兜底**，多重故障平滑回退、不断流
- **SWR 毫秒秒开 + 边缘防抖 + 换台防抖**，彻底消除黑屏转圈
- **全链路统一 8767 单端口**，多协议内部静默协同、按需调度
- **数据持久化 + 400 故障自动愈合**，重启不丢设备身份

**关于 `-G` 后缀**：`-G` 表示「卫视完整版」补丁——内核不变，仅把上游精简掉的卫视频道恢复为全量 64 路。v7.4 起至 v9.0 的非 `-G` 版本实际只有 30 路（央视），**卫视频道缺失**；需要卫视请选对应 `-G` 版本，或直接用最新的 **v11.3-G**（已内置全量 64 路）。

**订阅路径差异**：v3.0 ~ v8.0、各 `-G` 版本、v9.5-G 及之后版本使用 `/all.m3u`；v7.4 / v8.1 / v9.0 改为 `/cctv.m3u`（其上访问 `/all.m3u` 会返回 404）。

**选型建议**：
- 🥇 想要最全 + 最新 → **v11.3-G**（推荐）
- 🎯 只要央视真 4K、不要卫视 → **v9.0**
- 🪶 老设备 / 追求最小体积 → **v8.0-G**（仅 83 MB）

> 💡 Docker Hub 当前可拉取标签为 `v11.3-G`（= `latest`）、`v10.0-G`、`v9.9.3-G`、`v9.9-G`、`v9.8-G`、`v9.6-G`、`v9.5-G` 等；更早版本为本地归档，可按需从源码目录构建。

## 🛠 v11.3 旗舰版 · 核心更新

1. **（修复）连续播放更稳定**：修复 CCTV-16 4K 等频道因重复取源而意外降档的问题。只要直播清单持续更新，就会沿用当前播放地址
2. **（优化）切回频道优先复用原地址**：同一设备会话中，5 分钟内切回频道，会优先用原地址读取最新直播清单
3. **（修复）取源失败不再重复计数**：高码率取源首次失败时，先尝试备用线路。15 秒后，下一次播放请求即可重试高码率

### 📜 近期版本演进

- **v11.2-G**：切回频道重读清单复用播放地址；修复备用地址参数截断；回看分片转发改进；更新新疆卫视及三个剧场频道 SID

- **v9.9-G**（运行版本 9.9.1）：首次启播设备线路立即取清单；离台 20 秒停止后台轮询；缓存按分片推进计时（30 秒内复用）；JCE 限流直播与时移共享冷却（60 秒起逐次翻倍至 900 秒，尊重 Retry-After）；低码率无缓冲时返回 503 + Retry-After

- **v10.0-G**：双服务架构（Python 网关 + Rust Web 伴生来源）；BK 自动启播，高码率频道持续观看约 10 秒后台准备设备线路并平滑升档；按频道合并并发请求；36 条分片记录、发布最近 12 片、96 MB 共享内存

## 🚀 快速开始

### 方式一：docker run（最简单）

```bash
docker run -d --name ysp-live \
  -p 8767:8767 \
  -v ysp-live-data:/app/data \
  -e TZ=Asia/Shanghai \
  --restart unless-stopped \
  wuenci514/ysp-live:latest
```

### 方式二：docker compose

`docker-compose.yml`：

```yaml
services:
  ysp-live:
    image: wuenci514/ysp-live:latest
    container_name: ysp-live
    restart: unless-stopped
    ports:
      - "8767:8767"
    volumes:
      - ./data:/app/data
    environment:
      - TZ=Asia/Shanghai
```

```bash
docker compose up -d
```

## 📺 播放器接入

容器启动后，在播放器中添加订阅地址即可（台标与 EPG 节目单已内嵌，播放器自动匹配）：

| 用途 | 地址 |
| --- | --- |
| 本机播放 | `http://localhost:8767/all.m3u` |
| 局域网 / 电视盒子 | `http://<你的局域网IP>:8767/all.m3u` |
| 健康检查 | `http://localhost:8767/health` |
| 诊断日志 | `http://localhost:8767/diag` |

### 📱 APTV（TestFlight 版）

1. 进入「配置 → 服务 → 添加服务」。服务名称填「央视频直播」，服务类型选「Python」。
2. 代码来源选「远程链接」，填写 Python v11.3 脚本地址（`ysp-live-v11.3.py`）。
3. 点击「加载代码 → 添加服务」，启用服务。已有服务若支持编辑远程链接，可替换地址后重新加载。
4. 添加订阅：`http://127.0.0.1:8767/all.m3u`。

### 📱 nanoTV（TestFlight 版）

1. 进入「设置 → 通用 → 实验」，打开「JS 订阅」。
2. 进入「订阅 → 添加 → JavaScript」。
3. 填入 JavaScript 2.0.16 脚本地址（`ysp-service_2.0.16.js`）。⚠️ v11.2 起作者侧该 JS 脚本地址暂缺（原 2.0.16 链接已返回 404），可先用旧链接或改用 Python 路线。
4. 点击「读取脚本」→「批准并安装」，然后启用服务。

### 📱 mytv-android（最新预览版）

1. 在设置或网页面板搜索「Python运行环境」，也可从「设置 → 投屏与扩展 → 组件下载」安装。选 JavaScript 则无需安装 Python 组件。
2. 搜索「脚本服务」后点「添加服务」，或进入「设置 → 投屏与扩展 → 脚本服务 → 添加服务」。名称填「央视频直播」，代码来源选「远程链接」。
3. 选 Python 填 v11.3 脚本（`ysp-live-v11.3.py`）；选 JavaScript 填 2.0.16 脚本（`ysp-service_2.0.16.js`，地址暂缺时可改用 Python 路线）。勾选「启用」，点击「确定」。
4. 长按刚添加的服务，选「添加为订阅源」。

> 💡 脚本随版本发布包提供（`ysp-live-v11.3.py` / `ysp-engine.js`），`ysp-service_2.0.16.js` 见作者首发地址。

### 🚀 代理工具分流

1. **Shadowrocket**：「配置 → 模块 → ＋」，粘贴分流模块地址（`ysp.module`）。
2. **Surge / Loon / Clash 等**：通用规则集（`ysp.list`）。

### ⚠️ 使用提示

1. 建议在稳定网络下使用。真 4K 流量约 **15 GB/小时**，1080p 约 **5 GB/小时**，实际随码率浮动。
2. 健康检查：`http://localhost:8767/health`；诊断日志：`http://localhost:8767/diag`。
3. 服务运行在 NAS 或其他电脑时，把 `localhost` 换成该设备 IP。

> 💡 局域网其他设备播放时，若 m3u 内频道地址为绝对 `localhost`，需改用支持「按订阅主机补全相对地址」的播放器，或手动把 m3u 中的 `localhost` 替换为运行容器的电脑局域网 IP。

## 📌 注意事项

- **流量**：真 4K 约 15 GB/小时，1080p 约 5 GB/小时
- **网络**：建议在家庭宽带**直连**运行，不要在数据中心 / 云服务器上跑
- **实例数**：不要同时运行多个实例，容易触发央视频频控（HTTP 400）
- **数据**：`./data` 卷挂载保存设备身份，请勿删除，否则需重新注册
- 观看正式内容请通过官方渠道支持正版
