# 央视频全频道直播 (YSP Live) · Docker 镜像

> 🌐 **对外展示文档**（Docker Hub Repository overview）。内部完整管理与命名规范见同目录 `使用说明书.html` 与 `NAMING.md`。

基于 [Gary's Club](https://t.me/garysclub) 发布的「央视频全频道直播」项目打包的**开箱即用 Docker 镜像**。  
一条命令部署后，通过标准 IPTV 订阅地址（`.m3u` + EPG）即可把全部央视频道接入任意主流播放器。

> ⚠️ 本项目为第三方直播源代理工具，**仅供个人学习研究使用**。  
> 首发地址：社区 [Gary's Club](https://t.me/garysclub) · 频道 [Gary's Club Channel](https://t.me/garysclubchannel)。其他任何分发渠道均非作者本人！

---

## ✨ 核心亮点

- **真 4K 超高清**，内置全部 **64 路**独立频道（央视 30 + 卫视 34）
- **原生 7 天时移回看**，完美适配 TiviMate / APTV / PotPlayer / VLC 等主流播放器
- **双引擎四层全自动兜底**，多重故障平滑回退、不断流
- **SWR 毫秒秒开 + 边缘防抖 + 换台防抖**，彻底消除黑屏转圈
- **全链路统一 8767 单端口**，多协议内部静默协同、按需调度
- **数据持久化 + 400 故障自动愈合**，重启不丢设备身份

| v7.4 | 30（仅央视，无卫视） | `/cctv.m3u` | python:3.11-slim | 187 MB | 此后卫视一度缺失 |
| v7.0 | 64（央视 + CGTN + 卫视） | `/all.m3u` | python:3.11-slim | 187 MB | — |
| v3.0 | 63 | `/all.m3u` | python:3.12-slim | 184 MB | 早期经典版本 |

**关于 `-G` 后缀**：`-G` 表示「卫视完整版」补丁——内核不变，仅把上游精简掉的卫视频道恢复为全量 64 路。v7.4 起至 v9.0 的非 `-G` 版本实际只有 30 路（央视），**卫视频道缺失**；需要卫视请选对应 `-G` 版本，或直接用最新的 **v9.5-G**（已内置全量 64 路）。

**订阅路径差异**：v3.0 ~ v8.0、各 `-G` 版本、v9.5-G 使用 `/all.m3u`；v7.4 / v8.1 / v9.0 改为 `/cctv.m3u`（其上访问 `/all.m3u` 会返回 404）。

**选型建议**：
- 🥇 想要最全 + 最新 → **v9.5-G**（推荐）
- 🎯 只要央视真 4K、不要卫视 → **v9.0**
- 🪶 老设备 / 追求最小体积 → **v8.0-G**（仅 83 MB）

> 💡 Docker Hub 当前可拉取标签为 `v9.5-G` 与 `latest`；更早版本为本地归档，可按需从源码目录构建。

## 🚀 快速开始

### 方式一：docker run（最简单）

```bash
docker run -d --name ysp-live \
  -p 8767:8767 \
  -v ysp-live-data:/app/data \
  -e TZ=Asia/Shanghai \
  --restart unless-stopped \
  wuenci514/ysp-live:latest
```

### 方式二：docker compose

`docker-compose.yml`：

```yaml
services:
  ysp-live:
    image: wuenci514/ysp-live:latest
    container_name: ysp-live
    restart: unless-stopped
    ports:
      - "8767:8767"
    volumes:
      - ./data:/app/data
    environment:
      - TZ=Asia/Shanghai
```

```bash
docker compose up -d
```

## 📺 播放器接入

容器启动后，在播放器中添加订阅地址即可（台标与 EPG 节目单已内嵌，播放器自动匹配）：

| 用途 | 地址 |
| --- | --- |
| 本机播放 | `http://localhost:8767/all.m3u` |
| 局域网 / 电视盒子 | `http://<你的局域网IP>:8767/all.m3u` |
| 健康检查 | `http://localhost:8767/health` |
| 诊断日志 | `http://localhost:8767/diag` |

> 💡 局域网其他设备播放时，若 m3u 内频道地址为绝对 `localhost`，需改用支持「按订阅主机补全相对地址」的播放器，或手动把 m3u 中的 `localhost` 替换为运行容器的电脑局域网 IP。

## 📌 注意事项

- **流量**：真 4K 约 15 GB/小时，1080p 约 5 GB/小时
- **网络**：建议在家庭宽带**直连**运行，不要在数据中心 / 云服务器上跑
- **实例数**：不要同时运行多个实例，容易触发央视频频控（HTTP 400）
- **数据**：`./data` 卷挂载保存设备身份，请勿删除，否则需重新注册
- 观看正式内容请通过官方渠道支持正版
